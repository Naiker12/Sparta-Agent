# Dirección visual

Concepto: seguir una misma hoja desde la intención hasta un cambio comprobado.

Paleta de la documentación: fondo #111210, panel #191a17, texto #edede7, texto secundario #a1a399, acento #dfd68b, borde #36382f. Inter embebida; monospace del sistema solo para etiquetas de archivo de demostración.

Un folio es el objeto continuo. Títulos de 76 px; explicaciones de 32 px; etiquetas de 24 px. Área segura 100 px. Cabecera anclada arriba, progreso de capítulos abajo. La narración visual alterna petición, documento, alcance y comparación. Fondo sólido: la lectura no necesita decoraciones en movimiento. La animación sirve para señalar entrada, selección y cambio.

No mostrar una interfaz inventada de Sparta. Rótulo «Flujo ilustrado» permanente. No autoproclamar ejecución exitosa del producto. El antes/después es un ejemplo pedagógico.
