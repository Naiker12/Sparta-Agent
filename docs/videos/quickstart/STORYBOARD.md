# Inicio rápido · Tutorial visual

60 segundos. Paleta de Sparta. Adaptador GSAP y control de progreso.

## Frame 1
status: animated
src: compositions/startup.html
time: 0–10s

Bienvenido a Sparta Agent. Instala la aplicación de escritorio y prepara tu entorno de trabajo.

Descarga siempre la versión compatible desde las releases oficiales.

## Frame 2
status: animated
src: compositions/engine.html
time: 10–20s

El motor prepara sus dependencias. El sistema configura el entorno Python en tu directorio de datos.

Abre los detalles de la consola si necesitas inspeccionar la descarga.

## Frame 3
status: animated
src: compositions/providers.html
time: 20–30s

Conecta tu proveedor de inferencia. Configura un modelo local (Ollama) o remoto (OpenAI, Anthropic, Gemini).

Introduce las credenciales en configuración, nunca en el chat.

## Frame 4
status: animated
src: compositions/prompt.html
time: 30–40s

Envía tu primera conversación. Comprueba que el modelo responde antes de habilitar herramientas.

Una respuesta confirma el flujo básico de comunicación.

## Frame 5
status: animated
src: compositions/response.html
time: 40–50s

El modelo responde con éxito. Observa la velocidad de generación y la calidad de la respuesta.

El motor está preparado para asociar proyectos y carpetas.

## Frame 6
status: animated
src: compositions/finish.html
time: 50–60s

Tu entorno está listo para crear. Vincula una carpeta y continúa con la guía «Tu primera tarea».

Continúa en la documentación con «Tu primera tarea».
