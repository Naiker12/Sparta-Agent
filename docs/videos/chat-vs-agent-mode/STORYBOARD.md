# Chat vs Modo Agente · Tutorial visual

60 segundos. Paleta de Sparta. Adaptador GSAP y control de progreso por pasos.

## Frame 1
status: animated
src: compositions/mode-selector.html
time: 0–10s

Dos modos. Diferentes permisos. Sparta separa la consulta segura de la modificación con herramientas.

El modo seleccionado define si el modelo solo analiza o puede actuar.

## Frame 2
status: animated
src: compositions/chat-mode.html
time: 10–20s

Lectura y búsqueda sin riesgo. Permite inspeccionar, listar y entender tus archivos sin alterar nada.

En Modo Chat queda prohibido crear, modificar o eliminar archivos.

## Frame 3
status: animated
src: compositions/safety-guard.html
time: 20–30s

¿Intentas editar en Modo Chat? Si pides una edición o borrado, el sistema detiene la acción y te avisa.

El modelo no puede saltarse la protección de solo lectura.

## Frame 4
status: animated
src: compositions/agent-mode.html
time: 30–40s

Edición y comandos bajo tu mando. Habilita herramientas de escritura y ejecución en tu espacio de trabajo.

Cada modificación exige una tarjeta de confirmación previa.

## Frame 5
status: animated
src: compositions/permission-modal.html
time: 40–50s

Tú apruebas cada cambio antes de actuar. Revisa la herramienta, el archivo exacto y el contenido propuesto.

Si el alcance no coincide con lo esperado, rechaza la acción.

## Frame 6
status: animated
src: compositions/summary.html
time: 50–60s

Consulta. Autoriza. Verifica. Un flujo predecible garantiza que tu proyecto se mantenga seguro.

Más detalles en la guía: «Chat y modo agente».
