# Sparta Agent v0.2.17

## Carpeta de trabajo por chat

- Cada chat puede tener una carpeta local independiente, elegida desde el compositor.
- Se ofrecen permisos de solo lectura, edición sin eliminación y edición completa.
- La carpeta no se mezcla con las Fuentes de Proyecto ni se indexa automáticamente.

## Documentos y archivos

- Se añadieron lectores para Excel, CSV, PowerPoint, OpenDocument, RTF, EPUB y JSON.
- Las herramientas de la carpeta pueden extraer contenido de PDF, Word, Excel y documentos compatibles bajo demanda.

## Seguridad y estabilidad

- Las operaciones de archivos quedan limitadas a la carpeta autorizada por el chat.
- Se bloquearon los cambios incompatibles con el permiso elegido.
