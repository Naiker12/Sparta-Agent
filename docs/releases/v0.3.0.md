# Sparta Agent v0.3.0

## Resumen

La versión 0.3.0 consolida Sparta Agent como un espacio de trabajo que se conecta a proveedores de IA mediante API. La aplicación no descarga, instala ni ejecuta modelos locales: las conexiones se configuran con las credenciales o URL de servidor que el usuario ya administra.

## Cambios principales

- Conexiones de proveedores API, incluidos servidores compatibles locales o remotos ya existentes.
- Selector de proveedores con iconos de marca incluidos en el empaquetado de escritorio.
- Landing y documentación actualizadas para explicar el flujo de configuración por API.
- Panel de ajustes de ejecución más legible en escritorio y ventanas compactas.
- Explorador lateral vinculado al proyecto activo: al conectar una carpeta, sus archivos se muestran directamente en el panel de archivos.

## Validación

- Comprobación de tipos de TypeScript.
- Suite automatizada de pruebas.
- Build de la landing.
- Build y verificación del empaquetado de escritorio.
