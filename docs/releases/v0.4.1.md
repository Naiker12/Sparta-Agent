# Sparta Agent 0.4.1

Esta actualización incorpora tareas programadas desde la conversación y mejora la continuidad al crear documentos, abrir sus resultados y recuperar preferencias. Si vienes de 0.3.3, reúne las funciones nuevas y las correcciones desarrolladas desde esa versión; no hubo una publicación intermedia de 0.4.0.

## Nuevas funciones

- **Programa desde el chat:** pide una tarea o usa «Programar tarea» en el menú del compositor. Revisa instrucciones, horario, zona horaria, proveedor y modelo antes de activarla.
- **Propuestas desde Telegram:** el propietario autorizado puede revisar y confirmar una tarea. La confirmación caduca y no concede permisos para archivos locales.
- **Resultados en su conversación:** las ejecuciones conservan su chat y los avisos recientes pueden abrirlo cuando la aplicación está visible.
- **Documentación actualizada:** guías de automatizaciones, canales, documentos y diagnóstico, con enlaces a los instaladores de esta versión.

## Qué se corrigió y mejoró

- Guardar un borrador, probar manualmente y activar una automatización tienen estados diferenciados. Los errores de configuración indican qué revisar.
- Se rechazan documentos sin contenido útil y se corrige la apertura inicial de Word, PDF y hojas de cálculo, evitando estados de visor sin inicializar.
- La generación de documentos presenta un progreso compacto, detalles Python desplegables y respeto por la preferencia de movimiento reducido. Se elimina un ciclo de imports que impedía iniciar herramientas Python.
- La selección de mascota conserva su cambio local mientras termina el guardado remoto. Se mejora la recuperación de proveedor, modelo y preferencias entre chats.
- El arranque de Electron cancela correctamente operaciones pendientes y evita reutilizar credenciales de procesos detenidos.
- El renderizado Markdown durante streaming y el restablecimiento de preferencias del indicador de modelos se estabilizan.
- Los instaladores excluyen los entornos Python de desarrollo. Los nombres de descarga y metadatos del actualizador usan la misma versión del producto.

## Descargar y actualizar

Elige el instalador **0.4.1** de tu plataforma en los archivos de esta release:

- Windows x64: `Sparta-Agent-Windows-0.4.1-Setup.exe`.
- macOS Apple silicon: `Sparta-Agent-Mac-0.4.1-arm64-Installer.dmg`.
- macOS Intel: `Sparta-Agent-Mac-0.4.1-x64-Installer.dmg`.
- Linux x64: `Sparta-Agent-Linux-0.4.1.AppImage`.

Instala sobre la versión anterior para conservar tus datos. Desinstalar elimina los datos locales de Sparta; no es necesario hacerlo para actualizar. Los ZIP de macOS, blockmaps y archivos `latest*.yml` sirven al actualizador y no sustituyen al instalador de tu plataforma.

## Requisitos y alcance

Sparta y su backend deben permanecer abiertos para ejecutar tareas programadas. Se necesita un proveedor y un modelo compatibles con las herramientas que pidas; una prueba manual no activa un borrador. Telegram requiere un bot configurado y una cuenta autorizada. Discord, WhatsApp y Slack siguen pendientes.

La validación automatizada cubre 3.629 pruebas frontend con Node 22 y Node 24, además de backend, tipos y flujos de navegador de automatizaciones y documentos. Las pruebas de navegador usan proveedores simulados; no certifican todas las cuentas externas ni combinaciones de modelos. El proceso de publicación exige que compilen las cuatro plataformas y que coincidan versiones, tamaños y checksums de los archivos del actualizador.
