# Sparta Agent v0.3.3

Esta versión mejora el trabajo con proyectos, la continuidad de las conversaciones y la claridad del estado de las tareas. La aplicación continúa usando proveedores de IA por API; no distribuye motores de modelos locales.

## Novedades

- Cola de mensajes guardada antes del envío, con recuperación explícita de pendientes tras reabrir la aplicación.
- Bandeja de trabajo junto a Automatizaciones: filtros, búsqueda, resultados y accesos al chat.
- Revisión de propuestas de automatizaciones y extracciones de memoria de conversaciones.
- Demo interactiva en la landing, alineada con los controles y colores del escritorio.
- Documentación organizada en guías, arquitectura y desarrollo, con diagramas y navegación revisada.

## Correcciones

- Los mensajes ya despachados no se vuelven a enviar automáticamente al recuperar una cola. Los casos sin confirmación requieren revisión.
- Las respuestas incompletas no se presentan como trabajo completado.
- Una lectura de imagen finalizada después de cerrar el selector ya no modifica el campo ni muestra errores tardíos.
- El build independiente del frontend define correctamente la versión y evita la pantalla en blanco.
- El backend muestra la versión del producto en lugar de una versión heredada.
- Se retiraron archivos sin uso confirmado, capturas antiguas, scripts temporales y comentarios redundantes.

## Uso y límites

Conecta tu proveedor por API después de preparar el backend local. La demo del sitio usa datos de ejemplo y no ejecuta herramientas ni accede a tus archivos. La bandeja refleja resultados comunicados por el runtime del chat; no verifica de forma independiente los efectos externos de las herramientas.

Las comprobaciones de publicación y sus resultados se registran en `docs/audits/2026-10-02-release-0.3.3.md`. No se atribuyen a esta release funciones propuestas que todavía no están implementadas.
