# Sparta Agent 0.5.4

**Actualización de mantenimiento.** Corrige problemas de creación de archivos de código, vistas previas locales y coordinación de los paneles del chat.

## Correcciones

- `generate_document` puede guardar fuentes de código como texto UTF-8 sin ejecutar su contenido ni habilitar Python. Las rutas siguen sujetas a la carpeta vinculada y los permisos activos.
- La vista previa de HTML autentica la lectura y empaqueta recursos estáticos permitidos dentro del visor aislado. Los módulos JavaScript y TypeScript que requieren compilación siguen necesitando un preview de proyecto.
- Las vistas de archivos, lienzos HTML y navegación web comparten la superficie de preview sin sustituirse entre sí ni abrir `localhost:4200` de forma automática.
- Se retiraron los visores locales de texto e imagen que habían quedado sin uso; el explorador conserva la lista de archivos y la revisión de Git.
- Se alineó la resolución de React en el arranque raíz para evitar una pantalla en blanco por mezclar runtimes.
- La revisión de cambios por respuesta conserva identidad, estados de error y selección correcta cuando las lecturas terminan fuera de orden.
- Se refinó el tamaño, interlineado y numeración de la vista de código, además del hover de los divisores de panel.

## Actualización y plataformas

Se preparan instaladores para Windows x64, macOS Apple silicon, macOS Intel y Linux x64 después de completar las puertas automatizadas.

## Alcance

El preview estático no transpila TypeScript ni empaqueta proyectos con módulos ES. La ruta escrita en un mensaje no concede acceso a una carpeta: para guardar en un workspace, este debe estar conectado y tener permisos suficientes. Las pruebas automatizadas no sustituyen la validación de cada proveedor externo configurado.
