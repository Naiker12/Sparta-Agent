# Sparta Agent v0.2.10

## Novedades

- Cada conversación recibe automáticamente la fecha, hora, día de la semana y zona horaria locales del equipo. El modelo puede interpretar correctamente referencias temporales como «hoy», «mañana» y «la próxima semana».
- Las actualizaciones de escritorio se instalan de forma silenciosa y la desinstalación de Windows limpia los datos de Sparta Agent.
- Se evitó una ruta de clonación recursiva del historial que podía mostrar `Maximum call stack size exceeded` al enviar o reintentar un mensaje.

## Notas de distribución

La firma y notarización de código están preparadas para credenciales de CI. Los avisos de confianza de Windows o macOS se eliminarán al configurar certificados válidos de cada plataforma.
