# Sparta Agent v0.2.6

## Workspace de proyectos

- Una carpeta conectada se usa como workspace activo del proyecto.
- El agente puede listar, leer, buscar, crear, editar, renombrar y eliminar archivos mediante tools aisladas al workspace.
- Las operaciones de escritura, creación, renombre y eliminación mantienen la confirmación de permisos.
- El explorador de carpeta permite abrir y guardar archivos de texto desde la aplicación de escritorio.

## Seguridad y fiabilidad

- Las rutas de archivos se validan en backend con protección contra traversal, symlinks y junctions fuera del workspace.
- Los endpoints de filesystem devuelven un estado claro cuando el proyecto no tiene una carpeta conectada.
- Se mantienen límites para archivos de texto y exclusiones de directorios pesados en las búsquedas.

## Verificación

- Lint, typecheck, pruebas unitarias y pruebas de regresión Electron ejecutadas antes del release.
