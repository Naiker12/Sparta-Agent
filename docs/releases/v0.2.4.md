# Sparta Agent v0.2.4

## Correcciones de distribución

- Se sincronizó `package-lock.json` con `package.json` para que `npm ci` pueda instalar el proyecto de forma reproducible en GitHub Actions.
- Se incorporó la resolución anidada requerida de `@pierre/theme@1.1.0` por `@pierre/trees`.
- Los workflows de CI, Release y la landing usan `npm ci` sin el fallback a `npm install`; una desincronización vuelve a fallar de forma explícita.
- Se actualizaron las acciones de checkout y setup de Node a v5.

## Aplicación de escritorio

- La sección **Acerca de** toma la versión de la aplicación Electron empaquetada y ya no puede ser sobrescrita por la versión del backend Python.
- El empaquetado valida que `app.asar` incluya el renderer, el proceso principal y una versión coincidente.
- Se valida que el bundle contenga `dist/index.html`, evitando la pantalla de ruta no encontrada tras instalar.
- El primer arranque puede preparar el runtime del backend y muestra progreso o un error accionable si no puede iniciarlo.

## Verificación realizada

- Instalaciones limpias de raíz y frontend con npm 10, equivalente al entorno Node 22 de GitHub Actions.
- TypeScript, pruebas de regresión Electron y pruebas raíz superadas.
- Instalador Windows `Sparta-Agent-Windows-0.2.4-Setup.exe` generado y verificado localmente.

## Descargas

Los artefactos publicados por GitHub Actions estarán disponibles en esta versión para Windows, macOS y Linux.
