# Sparta Agent v0.2.8

## Una actualización de escritorio más clara y confiable

Sparta Agent v0.2.8 mejora el ciclo completo de actualización de la aplicación y corrige detalles importantes de la interfaz de escritorio. Esta entrega está orientada a que instalar una nueva versión sea un proceso entendible, controlado y acompañado por información útil sobre los cambios que recibes.

## Novedades principales

### Actualizaciones nativas desde la aplicación

La versión de Electron incorpora un actualizador integrado. Cuando exista una versión publicada, Sparta Agent puede comprobarla, mostrar su disponibilidad, descargarla bajo tu control y aplicar la instalación al reiniciar. Durante la descarga se informa el progreso y, si ocurre un problema, se ofrece una acción para intentarlo de nuevo.

El flujo no instala una actualización de manera silenciosa: primero se muestra el aviso, las notas de la versión y la acción de descarga. La aplicación solo se reinicia cuando eliges instalar la versión ya descargada.

### Notas de versión dentro de la app

El aviso de actualización ahora puede mostrar un resumen de las mejoras y abrir las notas completas del release. Esto permite revisar qué cambió antes de descargar, sin tener que buscar la publicación en el navegador.

También se ajustó el proceso de publicación para incluir los metadatos necesarios de cada plataforma. Windows, macOS y Linux publican sus instaladores junto con los archivos de actualización que necesita el cliente de escritorio.

### Tablas Markdown a pantalla completa

Corregimos la vista ampliada de las tablas generadas en el chat. Antes, el área de controles podía quedar oculta detrás de la barra de título de Windows y no era posible cerrar la tabla con normalidad. Ahora el contenido ampliado comienza debajo del área reservada para la ventana, por lo que los controles siguen disponibles y la vista puede cerrarse correctamente.

### Barra de título y panel lateral alineados

La línea divisoria superior de Electron ahora sigue la geometría real del panel lateral. Al abrir, cerrar, fijar o redimensionar el sidebar, el borde se adapta sin atravesar el encabezado, invadir el contenido ni dejar bloques visuales durante la transición.

### Ajustes de ejecución en el idioma seleccionado

Los controles de ejecución completan su localización. Etiquetas como el estado guardado, el ejemplo de instrucción del sistema, Presence Penalty y Max Tokens ahora se muestran en español cuando ese es el idioma activo. Los preajustes existentes se conservan de forma compatible.

## Publicación y actualización

- Versión del paquete, shell de escritorio, landing, enlaces de descarga, README y referencias de interfaz actualizados a `0.2.8`.
- Los artefactos de release incluyen instaladores y archivos de actualización para que las instalaciones existentes puedan detectar futuras versiones.
- Las notas de esta publicación se usan tanto en GitHub Releases como en la experiencia de actualización dentro de Sparta Agent.
