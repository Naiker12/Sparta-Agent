# Sparta Agent 0.5.2

**Actualización de mantenimiento.** Esta versión corrige un error de JavaScript que impedía iniciar la aplicación de escritorio en Windows.

## Correcciones

- El proceso principal de Electron ahora proporciona `require` al bundle ESM para que las dependencias CommonJS puedan cargar módulos nativos de Node.js, incluido `fs`.
- Se conserva el aislamiento de contexto y la integración limitada de Node.js en el renderer.

## Actualización y plataformas

La release incluye instaladores de Windows x64, macOS Apple silicon, macOS Intel y Linux x64, generados y validados por el flujo automatizado de publicación.

## Validación

La publicación se realiza después de completar las comprobaciones de calidad, los builds de las cuatro plataformas y la validación de los instaladores y de la documentación.
