# Sparta Agent 0.5.5

**Actualización de mantenimiento.** Corrige el icono de la aplicación de Windows que podía aparecer como un archivo genérico en la barra de tareas después de instalar Sparta.

## Correcciones

- El empaquetado de Windows utiliza `spartan.ico` como icono de la aplicación, el ejecutable y el instalador, para mantener la misma identidad visual en la ventana, la barra de tareas y los accesos directos.
- La validación del paquete comprueba que el recurso del icono de Windows esté incluido.

## Actualización y plataformas

Se generó localmente el instalador de Windows x64: `Sparta-Agent-Windows-0.5.5-Setup.exe`. Todavía no está publicado. La publicación oficial requiere completar los builds de macOS Apple silicon, macOS Intel y Linux, además de las validaciones finales del release.

## Validación

El build local de Windows x64 completó typecheck, compilación del renderer y Electron, empaquetado NSIS y validación de `app.asar`; se confirmó que el paquete contiene `dist/spartan.ico`. La compilación mostró advertencias de Vite/Rolldown por opciones y anotaciones de dependencias, sin impedir el empaquetado. Esta comprobación no incluye instalación y verificación visual del icono en una sesión de Windows limpia.
