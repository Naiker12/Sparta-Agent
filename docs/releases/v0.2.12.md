# Sparta Agent v0.2.12

Esta versión mejora la experiencia del agente de escritorio y refuerza los límites de seguridad del workspace.

## Novedades

- Se puede proponer la conexión de una carpeta al pegar una ruta absoluta o soltar una carpeta en el chat.
- La conexión solicita explícitamente acceso de solo lectura o lectura/escritura antes de habilitarla.
- Un chat sin proyecto puede crear y asociar un proyecto al conectar una carpeta.
- El contexto del agente refleja el permiso elegido y mantiene la carpeta activa al abrir el proyecto.

## Seguridad y estabilidad

- Las rutas de archivos se validan antes de consultar adjuntos en caché.
- Las operaciones de escritura, creación y borrado se rechazan en workspaces de solo lectura.
- Se corrige un error de actualización interna del compositor al interceptar una ruta antes del envío.
- El workflow de release usa Node 22, ejecuta las verificaciones previas y publica con `softprops/action-gh-release@v3`.
