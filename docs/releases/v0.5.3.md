# Sparta Agent 0.5.3

**Actualización de mantenimiento.** Esta versión corrige el inicio del backend en la aplicación de escritorio empaquetada.

## Correcciones

- El router RAG ahora es opcional al iniciar el backend. La distribución API-only omite intencionalmente `routes/rag_pkg` y el motor RAG completo; su ausencia ya no detiene la aplicación con `ModuleNotFoundError`.
- La validación del paquete revisa que el backend distribuido tolere esa configuración y falle durante la compilación si la protección desaparece.

## Actualización y plataformas

La publicación incluye instaladores para Windows x64, macOS Apple silicon, macOS Intel y Linux x64 después de completar las comprobaciones automatizadas.

## Alcance

Esta corrección permite completar la preparación del backend de la edición API-only. No habilita las funciones RAG que requieren el motor excluido de esa distribución.
