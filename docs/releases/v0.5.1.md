# Sparta Agent 0.5.1

**Ya disponible.** Esta actualización corrige las notas que aparecen en el aviso del actualizador.

## Correcciones

- El aviso consulta las releases oficiales de Sparta Agent y carga únicamente las notas cuyo tag corresponde a la versión que ofrece instalar.
- Si no hay notas para esa versión, el aviso deja de mostrar por error las novedades de otro proyecto.
- El título del aviso identifica correctamente a Sparta Agent en español e inglés.

## Actualización y plataformas

Descarga el instalador adecuado desde [GitHub Releases](https://github.com/Naiker12/Sparta-Agent/releases/tag/v0.5.1): Windows x64, macOS Apple silicon, macOS Intel o Linux x64. La release incluye EXE, DMG y ZIP para macOS, y AppImage, junto con los metadatos del actualizador.

## Validación

La release se publica tras completar las comprobaciones automatizadas, los builds de las cuatro plataformas y la validación de los instaladores.
