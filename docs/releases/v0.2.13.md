# Sparta Agent v0.2.13

Esta versión corrige problemas importantes del sistema de autoactualización y mejora la experiencia del aviso dentro de la aplicación.

## Novedades

- El aviso de actualización puede minimizarse a un indicador flotante y restaurarse cuando sea necesario.
- Durante la descarga minimizada se muestra el porcentaje de progreso.
- Las novedades incluidas por Electron aparecen inmediatamente mientras se carga la versión enriquecida desde el backend.
- La consulta de notas de versión reintenta automáticamente los fallos transitorios.

## Seguridad y estabilidad

- macOS genera y publica el archivo ZIP requerido por Squirrel.Mac, además del instalador DMG y `latest-mac.yml`.
- Las notas de versión se conservan al terminar la descarga y durante la preparación del reinicio.
- Linux comprueba que Sparta Agent se ejecute desde un AppImage válido antes de intentar una instalación automática.
- Los entornos Linux incompatibles muestran un error claro y conservan la opción de descarga manual.
