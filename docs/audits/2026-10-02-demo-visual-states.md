# Revisión de estados visuales

Se comparó la demo con los componentes de bienvenida, encabezado de sidebar, razonamiento y controles del escritorio. La comparación usa el código fuente y las capturas proporcionadas; no supone una captura simultánea de una instancia nativa.

## Correcciones

- El logo del sidebar vuelve al chat vacío mediante un botón accesible.
- El sidebar contraído conserva avatar y acceso a configuración.
- El saludo usa apodo o primer nombre, limitado a veinte caracteres, como el escritorio.
- La aprobación muestra el archivo que se editaría, en lugar del nombre del documento de propuesta.

## Comprobaciones

Se verificaron inicio desde el logo, acceso a configuración con sidebar contraído, controles de generación y aprobación manual. Se revisó el diálogo de Apariencia en tema oscuro y viewport móvil de 390 × 844; el diálogo cabe dentro del viewport y mantiene sus controles y desplazamiento. Modelo y micrófono permanecen visibles en el composer móvil.

El flujo pausa la animación cuando la página está oculta. Las respuestas, herramientas y aprobaciones siguen siendo ejemplos locales. Estas comprobaciones no equivalen a paridad funcional completa con el escritorio.
