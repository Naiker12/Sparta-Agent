# Modo Chat vs Modo Agente

Sparta Agent implementa una separación estricta entre dos modos de trabajo para garantizar que ninguna acción de modificación, escritura en disco o ejecución de comandos se realice sin tu consentimiento expreso.

---

## Modo Chat (Solo Lectura y Consulta)

El **Modo Chat** está concebido para la exploración analítica, auditoría de código y consultas sin efectos secundarios en el sistema.

### Capacidades Permitidas en Modo Chat:
- **Búsqueda Web en Tiempo Real**: Ejecución de consultas web sintéticas y verificación de documentación oficial (`web_search`, `read_url_content`).
- **Lectura e Indexación del Workspace**: Listar carpetas, obtener metadatos y leer archivos de código (`list_files`, `search_files`, `read_file`).
- **Consultas al RAG Local**: Búsqueda semántica y recuperación de fragmentos sobre PDFs, documentos y repositorios.
- **Consultas en Servidores MCP**: Listar páginas de Notion, leer mensajes en canales de Slack o consultar eventos de Google Calendar.

### Restricciones del Modo Chat:
<Callout type="warn">
  En Modo Chat **queda estrictamente prohibido crear, modificar, editar o borrar recursos en disco o terminal**. Si solicitas una acción de escritura, el asistente indicará:
  
  *"Debes activar el Modo Agente en el selector de modo para crear, editar o borrar recursos."*
</Callout>

---

## Modo Agente (Modificación con Autorización)

El **Modo Agente** habilita capacidades completas de ingeniería de software autónoma: generación de código, refactorización multi-archivo, ejecución de pruebas en consola y operaciones en herramientas externas.

### Capacidades Habilitadas en Modo Agente:
- **Operaciones de Archivo**: Creación, sustitución parcial y eliminación de archivos en el workspace (`write_to_file`, `replace_file_content`, `multi_replace_file_content`).
- **Ejecución de Comandos**: Ejecución controlada en PowerShell, Zsh o Bash con gestión de procesos en segundo plano (`run_command`, `manage_task`).
- **Mutaciones en Servidores MCP**: Creación y actualización de páginas en Notion, subida de documentos a Google Drive, apertura de pull requests en GitHub y emisión de mensajes en Slack.
- **Gestión de Skills y Tareas Programadas**: Creación y activación de flujos especializados.

---

## Diálogo Modal de Permisos (Permission Request Dialog)

En Modo Agente, el subsistema **Permission Broker** intercepta cualquier llamada a herramientas de modificación antes de su ejecución:

1. **Inspección de Parámetros**: Muestra la ruta exacta del archivo, las líneas a sustituir o el comando de consola completo.
2. **Revisión del Diff**: Presenta el código agregado o eliminado antes de guardarse en el disco.
3. **Decisión Explícita**: El usuario debe presionar **Aprobar** o **Rechazar**. Ninguna herramienta puede eludir este paso.

---

## Matriz Comparativa de Seguridad

| Capacidad Operativa | Modo Chat | Modo Agente |
| :--- | :--- | :--- |
| **Lectura de código y archivos locales** | Permitido | Permitido |
| **Búsqueda web y Deep Research** | Permitido | Permitido |
| **Consultas a bases de datos (solo lectura)** | Permitido | Permitido |
| **Creación o edición de archivos en disco** | Bloqueado | Requiere Aprobación Modal |
| **Ejecución de scripts y comandos de terminal** | Bloqueado | Requiere Aprobación Modal |
| **Mutaciones en servidores MCP (Notion, Drive)** | Bloqueado | Requiere Aprobación Modal |
| **Auditoría de cambios en tiempo real** | Activa | Activa |
