## Conversación y ejecución

Una conversación puede explicar un problema, planificar un cambio o invocar herramientas disponibles. El comportamiento depende del modo seleccionado, del proveedor y de la política de herramientas activa.

Usa el modo de consulta para revisar información y pedir propuestas. Para realizar cambios, selecciona el modo agente y confirma que la tarea, la carpeta y las herramientas están delimitadas.

## Antes de una acción

- Comprueba el nombre y los argumentos de la herramienta.
- Revisa el comando completo si se utiliza la terminal.
- Identifica los archivos o servicios externos afectados.
- Acepta o rechaza las solicitudes de aprobación que muestre la aplicación.

## Durante la ejecución

Distingue la escritura de argumentos, la espera de aprobación y la ejecución real. Una herramienta solicitada todavía puede estar pendiente. La salida de la terminal aporta evidencia de lo que ocurrió.

## Al terminar

Pide una comprobación concreta: releer un archivo, ejecutar una prueba o revisar un diff. El texto final del modelo no sustituye esa evidencia.

Consulta [Seguridad y permisos](/docs/core-concepts/security-and-sandbox) para conocer los límites de las herramientas locales y remotas.
