# Modelos y Proveedores

Sparta Agent incorpora una pasarela agéntica flexible que permite alternar dinámicamente entre **modelos locales de máxima privacidad** y **los modelos más avanzados de la industria en la nube**.

---

## Modelos Locales (Inferencia 100% Offline)

Al operar con modelos locales, tus datos, código fuente y mensajes se procesan en tu propia GPU/CPU sin emitir un solo paquete hacia internet.

### Servidores y Motores Compatibles:
- **Ollama**: Integración automática con detección de modelos descargados (`http://localhost:11434`).
- **LM Studio**: Compatible con el servidor local de inferencia en el puerto `1234`.
- **vLLM / llama.cpp**: Soporte para formatos cuantizados GGUF (`Q4_K_M`, `Q8_0`) con aceleración por hardware (NVIDIA CUDA, Apple Silicon Metal, AMD ROCm).

### Modelos Locales Recomendados para Programación:
| Modelo | Parámetros | Context Window | Caso de Uso Óptimo |
| :--- | :--- | :--- | :--- |
| **Qwen 2.5 Coder** | 7B / 14B / 32B | 32k - 128k | Edición de código, refactorización y pruebas unitarias. |
| **Llama 3.3** | 70B | 128k | Razonamiento arquitectónico complejo y planificación. |
| **DeepSeek R1 (GGUF)** | 8B / 14B / 32B | 64k - 128k | Resolución de problemas matemáticos y depuración profunda. |

## Proveedores en la Nube

Para tareas que demandan la máxima capacidad cognitiva o ventanas de contexto masivas, Sparta Agent permite conectar los principales proveedores comerciales con almacenamiento de claves cifradas en tu sistema.

<Tabs items={['Anthropic', 'OpenAI', 'Google Gemini', 'DeepSeek Cloud', 'Groq / OpenRouter']}>
  <Tab value="Anthropic">
    - **Modelos**: Claude 3.7 Sonnet (con modo de pensamiento híbrido), Claude 3.5 Sonnet, Claude 3.5 Haiku.
    - **Ventana de Contexto**: 200.000 tokens.
    - **Características**: Soporte para Computer Use nativo, generación de diffs precisos y comprensión de bases de código complejas.
  </Tab>
  <Tab value="OpenAI">
    - **Modelos**: GPT-4o, GPT-4o-mini, o1, o3-mini.
    - **Ventana de Contexto**: 128.000 tokens.
    - **Características**: Excelente velocidad en llamadas a herramientas estructuradas (Function Calling) y soporte multimodal.
  </Tab>
  <Tab value="Google Gemini">
    - **Modelos**: Gemini 2.5 Flash, Gemini 2.5 Pro, Gemini 1.5 Pro.
    - **Ventana de Contexto**: 1.000.000 - 2.000.000 tokens.
    - **Características**: Análisis masivo de repositorios completos en una sola llamada de contexto.
  </Tab>
  <Tab value="DeepSeek Cloud">
    - **Modelos**: DeepSeek V3, DeepSeek R1.
    - **Ventana de Contexto**: 64.000 tokens.
    - **Características**: Razonamiento de alta densidad a costos de inferencia sumamente accesibles.
  </Tab>
  <Tab value="Groq / OpenRouter">
    - **Modelos**: Llama 3.3 70B Versatile, Qwen 2.5 72B, Mixtral 8x22B.
    - **Características**: Velocidades de streaming ultrarrápidas (>300 tokens/segundo en LPU Groq).
  </Tab>
</Tabs>

## Gestión Segura de Secretos (Vault Local)

<Callout type="info">
  Todas las API Keys introducidas en Sparta Agent se almacenan en un almacén de claves local cifrado mediante **AES-256-GCM**, vinculado a la clave maestra de tu sesión de usuario. Ninguna clave es transmitida a servidores de telemetría de Sparta Agent.
</Callout>
