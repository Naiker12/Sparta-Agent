## Navegación de escritorio

**Nuevo chat** inicia una conversación. **Chat temporal** presenta el modo temporal. **Proyectos** organiza carpetas y sus conversaciones; **Más** reúne acciones adicionales según la configuración. Los elementos marcados como próximos o deshabilitados no representan una función disponible.

La búsqueda permite localizar conversaciones. El perfil y los ajustes están al pie de la barra lateral. La navegación puede variar según preferencias y tamaño de ventana.

## Composer y contexto

| Control | Qué hace | Qué comprobar |
| --- | --- | --- |
| Carpeta | Vincula el contexto del hilo a una carpeta | Ruta, acceso y proyecto correcto |
| Adjuntos | Añade archivos concretos | Procesamiento y capacidades del modelo |
| Modelo | Selecciona una conexión y un modelo | Proveedor, acceso y coste |
| Permisos | Establece cómo se autorizan herramientas | Modo activo y alcance de la llamada |
| Razonamiento | Ajusta opciones compatibles con el modelo | No todos los proveedores admiten lo mismo |
| Dictado | Convierte voz en entrada de conversación | Disponibilidad y configuración de audio |
| Enviar / detener | Inicia o solicita detener la respuesta | Detener no revierte efectos ya realizados |

Vincular una carpeta no significa que el modelo ya haya leído todos sus archivos. El menú de modelo se abre desde el composer y permite buscar por modelo o proveedor.

## Panel lateral del proyecto

| Vista | Contenido | Disponibilidad |
| --- | --- | --- |
| Archivos | Exploración y lectura del contexto de carpeta | Vista básica del workspace |
| Cambios | Archivos modificados y diferencias | Cuando el contexto habilita Git |
| GitHub | Información de repositorio | Cuando esa capacidad está habilitada |
| Subagentes | Vista de agentes especializados | Según las capacidades del proyecto |
| Vista previa web | Superficie de navegador del proyecto | Cuando está disponible |

El panel empieza cerrado y se abre desde el rail derecho. Pulsar de nuevo la pestaña activa lo colapsa. En escritorio su anchura es ajustable. Un elemento visible de demostración no garantiza que una integración esté conectada o que una acción se haya ejecutado.
