## Identifica dónde falla

| Síntoma | Primera comprobación | Recuperación |
| --- | --- | --- |
| La aplicación no inicia | Mensaje y detalles del arranque | Comprueba escritorio y servicios auxiliares; conserva el error |
| Autenticación rechazada | Sesión; usuario y contraseña en acceso web | Reinicia el escritorio para renovar su sesión |
| El modelo no responde | URL, clave, acceso al modelo y cuota | Prueba un mensaje corto sin adjuntos |
| Una herramienta falla | Argumentos, salida y estado de los archivos | Lee de nuevo los archivos antes de repetir una edición |
| Telegram no responde | Aplicación abierta, conexión activa y usuario autorizado | Consulta [Canales y Telegram](/docs/features/channels) |
| Voz no disponible | Preparación local o conexión de transcripción | Consulta [Voz y audio](/docs/features/voice-audio) |

<Callout type="warn" title="Conserva la seguridad y los datos">
No desactives la autenticación para resolver un 401 ni borres los datos como primer paso. Una cancelación no revierte cambios ya aplicados.
</Callout>

## Comprueba con una petición pequeña

1. Envía un mensaje sin archivos ni herramientas.
2. Si funciona, agrega el contexto de forma gradual.
3. Activa una herramienta cada vez y revisa su resultado.
4. Guarda los pasos exactos que reproducen el fallo.

## Reporta el problema

Copia esta plantilla y completa solo datos que puedas compartir. Elimina claves, tokens, contenido privado y datos personales.

```text title="Plantilla de diagnóstico"
Sistema operativo:
Versión de Sparta:
Pantalla o función:
Proveedor y modelo:
Pasos para reproducir:
Resultado esperado:
Resultado observado:
Error visible sin secretos:
```

## Antes de reinstalar

Crea una copia de lo que necesites conservar. La política de borrado del instalador Windows está en revisión; no asumas que conserva todos los datos.
