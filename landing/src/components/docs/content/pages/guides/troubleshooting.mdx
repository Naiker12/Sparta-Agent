---
title: "Diagnóstico y reparación"
description: "Localiza el fallo antes de reinstalar o cambiar de modelo."
---

## El motor no inicia

Abre los detalles del arranque y conserva el mensaje. Distingue un Python ausente, dependencias incompletas y un proceso que inicia pero no anuncia su puerto. No borres el directorio de datos como primer paso.

## No se puede autenticar

Reinicia el escritorio para renovar el intercambio con su motor local. Para acceso web, revisa usuario y contraseña. No desactives la autenticación para resolver un error 401.

## El modelo no responde

Comprueba la conexión, el inventario y el estado de carga. Prueba un mensaje corto sin adjuntos. Si funciona, añade contexto y herramientas de forma gradual.

## Una herramienta falla

Revisa sus argumentos y salida. Si hubo una edición parcial, vuelve a leer los archivos antes de reintentar. Una cancelación puede dejar cambios ya aplicados.

## Reporta el problema

Incluye sistema operativo, versión de Sparta, proveedor/modelo, pasos para reproducir y error visible. Elimina secretos y datos personales del diagnóstico.

## Conserva tus datos

Antes de reinstalar o desinstalar, crea una copia de lo que necesites conservar. La política de borrado del instalador Windows está en revisión y no debe asumirse que conserva todos los datos.
