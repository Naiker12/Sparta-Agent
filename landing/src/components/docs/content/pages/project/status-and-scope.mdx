## Propósito

Sparta Agent busca reunir conversaciones, contexto de proyecto y herramientas en un escritorio con control humano. La edición descrita en el README usa proveedores de IA mediante API y mantiene el motor de coordinación en el equipo.

## Alcance de la versión publicada: 0.5.0

La versión 0.5.0 conserva las funciones de automatización y Bandeja de trabajo de versiones anteriores e incorpora un mapa de Memoria más fácil de explorar, paneles de trabajo junto al chat, respuestas interactivas y herramientas con permisos para Telegram, archivos y voz.

- Recupera mensajes pendientes desde su conversación.
- Un envío registrado no se repite automáticamente.
- Los resultados inciertos requieren revisión.
- La bandeja muestra resúmenes y enlaces al chat; sus filtros actúan sobre la página actual.

| Área | Alcance documentado |
| --- | --- |
| Conversaciones | Chat, contexto y presentación de respuestas progresivas |
| Proveedores | Conexiones API y selección de modelos disponibles |
| Proyecto | Carpeta vinculada, archivos y revisión de cambios |
| Herramientas | Operaciones locales o externas sujetas a capacidades y permisos |
| Integraciones | Servidores MCP y credenciales según el servicio |
| Documentación | Guías de uso, arquitectura, diagnóstico y desarrollo |

Consulta [Inicio rápido](/docs/quickstart) y [Tu espacio de trabajo](/docs/guides/workspace). La disponibilidad exacta depende de la versión instalada, el proveedor y las conexiones configuradas.

## Qué depende de la configuración

La visión, el razonamiento, las llamadas de herramientas y los límites de contexto dependen del modelo y su API. Las vistas de Git, GitHub, subagentes o navegador dependen de las capacidades del proyecto. Una conexión exitosa no verifica todas las operaciones de un servicio.

## Límites de la edición API-only

| Área | Alcance |
| --- | --- |
| Chat | Proveedores por API o un servidor compatible que hayas preparado |
| Modelos de chat locales | El instalador no administra sus pesos, entrenamiento ni motores |
| Contexto | Archivos y herramientas; sin promesa de índice vectorial ni RAG persistente |
| Transcripción | El desarrollo de Canales incorpora preparación de Whisper y proveedores externos; su validación real está pendiente |

Consulta [Voz y audio](/docs/features/voice-audio) para distinguir transcripción de modelos de chat.

Las carpetas y módulos de compatibilidad conservados en el repositorio no amplían por sí solos el alcance del producto. Los elementos marcados como próximos y las demostraciones deben distinguirse de las funciones disponibles.

## Prioridades de mejora propuestas

Estas prioridades sirven para ordenar trabajo; no son fechas de entrega ni anuncios de funcionalidades aprobadas.

| Prioridad | Resultado buscado | Evidencia de finalización |
| --- | --- | --- |
| Fidelidad de interfaz | Componentes y estados coherentes entre escritorio y sitio | Revisiones de escritorio, móvil y teclado |
| Claridad de contexto | Explicar qué carpeta, modelo y permisos se usan | Guías y controles que muestran ese alcance |
| Diagnóstico | Errores con causa y recuperación accionables | Casos reproducibles y comprobaciones por capa |
| Mantenimiento | Responsabilidades claras y menos duplicación | Contratos compartidos, builds y documentación vigentes |

## Cómo seguir cambios reales

La release **0.5.0** pasó las puertas de calidad, los builds de Windows, Linux y las dos arquitecturas de macOS, la validación de instaladores y las comprobaciones de documentación y landing. Los flujos automatizados de proveedores usan datos de prueba; configura y comprueba tu propio bot de Telegram y tus proveedores de voz antes de depender de esas integraciones.

Las [releases](https://github.com/Naiker12/Sparta-Agent/releases) describen las versiones publicadas. Los [issues](https://github.com/Naiker12/Sparta-Agent/issues) permiten seguir propuestas y defectos. Contrasta cualquier plan con su implementación y pruebas antes de atribuirlo a una versión.
