# Introducción a Model Context Protocol (MCP)

**Model Context Protocol (MCP)** es el protocolo estándar de código abierto diseñado para estandarizar la forma en que los modelos de inteligencia artificial se comunican con fuentes de datos externas, APIs, bases de datos y sistemas de archivos.

Sparta Agent incorpora soporte nativo como **Cliente MCP completo**, permitiendo orquestar múltiples servidores locales y remotos bajo una misma interfaz de ejecución segura.

## Principios del Protocolo MCP en Sparta Agent

1. **Transporte Estandarizado (JSON-RPC 2.0)**: Comunicación tipada sobre `stdio` o `SSE` (Server-Sent Events) con manejo de errores uniforme.
2. **Descubrimiento Dinámico de Capacidades**: El agente descubre dinámicamente las herramientas (`tools`), recursos (`resources`) y plantillas de prompts expuestos por cada servidor.
3. **Control de Permisos Intermediado**: Cualquier llamada a una herramienta MCP que realice mutaciones en un servicio externo debe ser aprobada explícitamente mediante el diálogo de permisos.
