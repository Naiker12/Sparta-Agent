# Configuración de Servidores MCP

Los servidores MCP se configuran de forma declarativa mediante un archivo `mcp_config.json` ubicado en la carpeta de configuración de tu usuario o en la raíz de tu proyecto.

---

## Estructura del Archivo `mcp_config.json`

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/ruta/a/tu/workspace"],
      "env": {}
    },
    "postgres": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres"],
      "env": {
        "POSTGRES_CONNECTION_STRING": "postgresql://usuario:password@localhost:5432/mibase"
      }
    },
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_PERSONAL_ACCESS_TOKEN": "ghp_xxxxxxxxxxxxxxxxxxxx"
      }
    }
  }
}
```

---

## Parámetros de Configuración

- **`command`**: Ejecutable a invocar (ej. `npx`, `node`, `python`, `uvx`, o un binario nativo).
- **`args`**: Lista de argumentos de línea de comandos para iniciar el servidor.
- **`env`**: Variables de entorno inyectadas de forma aislada al proceso hijo del servidor MCP.

---

## Verificación de Conexión

Al iniciar Sparta Agent o al recargar la configuración, el sistema inicializa los servidores MCP y reporta su estado en el panel de herramientas activas. Si un servidor falla al iniciar, los errores se registran en el visor de depuración de IPC.
