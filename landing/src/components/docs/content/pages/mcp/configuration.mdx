---
title: "Configurar MCP"
description: "Añade una conexión, verifica sus herramientas y prueba una operación de lectura."
---

## Añade el servidor

Abre la configuración de MCP e introduce la URL o el comando que requiera el servidor. Utiliza la documentación de su mantenedor para conocer transporte, argumentos y variables necesarias.

## Introduce las credenciales

Completa el método de autenticación que soporte la integración. Evita incluir claves en comandos que se copien a logs o capturas.

## Verifica la conexión

Comprueba el estado y la lista de herramientas. Empieza con una consulta de lectura que tenga un resultado conocido antes de solicitar escrituras.

## Resuelve errores

Si el proceso no inicia, revisa el ejecutable y sus dependencias. Si el servicio responde con un error de autenticación, revisa la credencial y el alcance de la cuenta. Si una herramienta falla, conserva su error y los argumentos sin secretos.

## Limita el alcance

Habilita solo las herramientas necesarias. Un catálogo amplio no mejora una tarea si expone operaciones que no necesitas.
