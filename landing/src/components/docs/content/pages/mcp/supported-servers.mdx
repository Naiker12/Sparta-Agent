# Servidores MCP Soportados

Sparta Agent es compatible con cualquier servidor que implemente la especificación estándar de MCP mediante transporte **STDIO** o **SSE (Server-Sent Events)**.

---

## 📦 Conectores Populares

### 1. Notion MCP Server
- **Lectura**: Buscar páginas, consultar bases de datos, leer bloques de contenido.
- **Escritura (Modo Agente)**: Crear nuevas páginas, agregar tareas en bases de datos, actualizar bloques.

### 2. Google Drive / OneDrive MCP
- **Lectura**: Listar archivos, descargar contenido de documentos, buscar por nombre o contenido.
- **Escritura (Modo Agente)**: Subir archivos, organizar carpetas.

### 3. Slack MCP
- **Lectura**: Listar canales, buscar hilos de conversación, leer mensajes recientes.
- **Escritura (Modo Agente)**: Enviar mensajes a canales o responder en hilos.

### 4. GitHub / Git MCP
- **Lectura**: Consultar issues, pull requests, commits y ramas.
- **Escritura (Modo Agente)**: Crear issues, comentar en PRs, hacer commit de cambios aprobados.

### 5. Filesystem MCP
- **Lectura/Escritura**: Acceso controlado a directorios autorizados en el equipo local.
