## Compatibilidad real

MCP es un protocolo, no una garantía de que cualquier servidor funcione con cualquier cliente. Comprueba el transporte, la autenticación y los requisitos de la versión que vas a instalar.

## Qué revisar

| Aspecto | Comprobación |
|---|---|
| Mantenedor | Repositorio y documentación oficiales |
| Transporte | Compatible con la configuración de Sparta |
| Permisos | Lectura y escritura que necesita la tarea |
| Dependencias | Ejecutable y runtime disponibles |
| Credenciales | Alcance mínimo y método de revocación |

## Prueba de aceptación

Lista las herramientas, ejecuta una lectura conocida y comprueba el resultado. Después prueba una escritura reversible solo si la necesitas y está autorizada.

No existe en esta guía una certificación universal de conectores. Registra la versión y el resultado de tu propia prueba.
