## Qué aporta una skill

Una skill reúne instrucciones y recursos para una clase de tarea. Puede orientar cómo investigar, producir un documento o utilizar una herramienta disponible.

## Instrucciones y ejecución

Una skill no instala automáticamente las dependencias de una herramienta ni concede permisos sobre una cuenta. Comprueba los requisitos antes de pedir una tarea que dependa de un servicio externo.

## Reglas de proyecto

Mantén instrucciones concretas: carpetas relevantes, comandos de comprobación y convenciones del equipo. Evita reglas contradictorias o que prometan capacidades no disponibles.

## Mantenimiento

Activa las habilidades relevantes y revisa las que apuntan a rutas o herramientas retiradas. La calidad del contexto importa más que el tamaño del catálogo.
