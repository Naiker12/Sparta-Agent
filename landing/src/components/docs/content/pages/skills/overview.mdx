# Visión General de Skills y Reglas

Sparta Agent permite extender las capacidades del agente y personalizar sus directivas de comportamiento mediante **Skills modulares** y **archivos de Reglas de Proyecto**.

---

## Reglas de Proyecto (`.agents/AGENTS.md`)

Puedes definir directivas estrictas de estilo de código, convenciones de arquitectura y restricciones de seguridad creando un archivo `AGENTS.md` dentro de la carpeta `.agents` de tu repositorio.

### Ejemplo de Archivo `AGENTS.md`:
```markdown
# Reglas de Proyecto — Backend API

1. **Convenciones de Código**:
   - Todo nuevo endpoint debe implementar esquemas de validación Zod / Pydantic.
   - Prohibido utilizar `any` explícito en TypeScript.

2. **Seguridad y Permisos**:
   - Nunca modificar archivos de migración de base de datos ya ejecutados en producción.
   - Ejecutar la suite de tests (`npm test`) antes de considerar completa cualquier tarea.
```

---

## Skills Modulares (`skills/<nombre>/SKILL.md`)

Las **Skills** son carpetas autocontenidas que enseñan al agente flujos de trabajo especializados:
- **`SKILL.md`**: Instrucciones principales con metadatos en YAML frontmatter (nombre, descripción y directivas).
- **`scripts/`**: Scripts auxiliares en Python, Node o Bash que el agente puede invocar.
- **`references/`**: Documentación técnica complementaria que el agente consulta bajo demanda.
