# Guía de Inicio Rápido

Aprende a instalar, configurar y ejecutar tu primera tarea autónoma con Sparta Agent.

---

<Steps>

### 1. Descarga e Instalación

Descarga el instalador oficial correspondiente a tu sistema operativo desde la sección de descargas o compílalo desde el código fuente:

<Tabs items={['Windows', 'macOS', 'Linux']}>
  <Tab value="Windows">
    1. Descarga el instalador `Sparta-Agent-Windows-0.2.9-Setup.exe`.
    2. Ejecuta el asistente de instalación.
    3. Sparta Agent se integrará en tu menú de inicio y configurará el canal IPC local de Windows.
  </Tab>
  <Tab value="macOS">
    1. Descarga el paquete `Sparta-Agent-Mac-0.2.9-Installer.dmg` (Universal: Apple Silicon M1-M4 & Intel).
    2. Arrastra `Sparta Agent.app` a tu carpeta de **Aplicaciones**.
    3. Otorga permisos de terminal cuando el sistema lo solicite para la ejecución de comandos locales.
  </Tab>
  <Tab value="Linux">
    1. Descarga el binario portable `Sparta-Agent-Linux-0.2.9.AppImage` o el paquete `.deb`.
    2. Otorga permisos de ejecución:
    ```bash
    chmod +x Sparta-Agent-Linux-0.2.9.AppImage
    ./Sparta-Agent-Linux-0.2.9.AppImage
    ```
  </Tab>
</Tabs>

---

### 2. Configuración del Proveedor de Modelos

En la barra de estado o en la ventana de **Ajustes**, selecciona tu motor de inferencia preferido:

- **Modelos Locales (Privacidad 100% Offline)**:
  - **Ollama**: Sparta Agent detecta automáticamente instancias de Ollama corriendo en `http://localhost:11434`.
  - **LM Studio / vLLM**: Compatible con cualquier endpoint compatible con OpenAI en tu red local.
  - **Modelos recomendados**: `qwen2.5-coder:7b`, `llama3.3:70b`, `deepseek-r1:14b`.

- **Proveedores en la Nube**:
  - Introduce tu API Key de Anthropic (Claude 3.7 / 3.5 Sonnet), OpenAI (GPT-4o), Google Gemini, DeepSeek o Groq.
  - Tus claves se almacenan cifradas localmente en tu sistema con **AES-256-GCM**.

---

### 3. Selección del Modo de Operación

En el selector inferior de la interfaz:
- **Modo Chat**: Para análisis exploratorio, lectura de archivos, búsqueda web y preguntas técnicas sin riesgo de modificación.
- **Modo Agente**: Para tareas de desarrollo activo (creación de archivos, refactorización, ejecución de suites de tests). Cada acción activará una tarjeta de confirmación en pantalla antes de aplicarse.

---

### 4. Ejecución de tu Primera Tarea

Escribe una instrucción en lenguaje natural para comprobar la capacidad del agente:

```text
Analiza la estructura del proyecto en esta carpeta, localiza posibles cuellos de botella en las consultas SQL y propón un plan de refactorización por etapas.
```

El agente generará un **plan visible por pasos** y esperará tu aprobación antes de realizar modificaciones.

</Steps>
