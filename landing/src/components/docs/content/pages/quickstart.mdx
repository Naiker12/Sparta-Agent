## Antes de empezar

Necesitas una instalación compatible con tu sistema y acceso a un proveedor de IA por API. Sparta no descarga modelos ni requiere GPU para el chat.

<Steps>
### Instala Sparta
Descarga el archivo correspondiente a tu plataforma desde las [versiones del repositorio](https://github.com/Naiker12/Sparta-Agent/releases). Usa el nombre del archivo publicado en esa versión; no reutilices enlaces de una versión antigua.

### Abre el chat
Abre **Nuevo chat**. Si aún no tienes una conexión, selecciona **Configurar proveedor API**.

### Conecta un proveedor
En la configuración de conexiones, añade tu proveedor y sus credenciales. Si ya ejecutas un servidor compatible en tu PC o red, usa **Servidor API compatible (local o remoto)** y su URL. Comprueba que el modelo aparece y puede responder antes de habilitar herramientas.

### Envía una conversación de prueba
Escribe: «Responde con una frase y explica qué información necesitas para ayudarme con un proyecto». Una respuesta confirma el flujo básico del proveedor, pero no comprueba todavía la ejecución de herramientas.
</Steps>

## Comprueba el flujo completo

Continúa con [Tu primera tarea](/docs/guides/first-task). Utiliza una carpeta pequeña de prueba, solicita una lectura y después un cambio acotado que puedas revisar.

<Callout title="No compartas secretos en el chat">Introduce las credenciales en la configuración del proveedor. No las incluyas en prompts, capturas o informes de diagnóstico.</Callout>

## Desarrollo desde el repositorio

```bash
git clone https://github.com/Naiker12/Sparta-Agent.git
cd Sparta-Agent
npm ci
npm --prefix desktop/frontend-spartan ci
npm run dev
```

El comando inicia Vite y Electron. Sparta no prepara ni descarga modelos como parte del arranque.
