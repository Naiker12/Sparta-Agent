# Arquitectura del Frontend

El frontend de Sparta Agent está construido con **React 18/19**, **TypeScript**, **Tailwind CSS** y la biblioteca **Assistant-UI** para ofrecer una experiencia fluida, moderna y con soporte integral para modo oscuro/claro.

---

## 🎨 Sistema de Componentes

- **Assistant-UI Runtime**: Control de flujos de mensajes, streaming token a token, bloques de código interactivos, herramientas visuales y tarjetas de confirmación.
- **Hugeicons & Lucide Icons**: Iconografía de alta definición con soporte para íconos especializados por tipo de archivo (`Pdf02Icon`, `Xls02Icon`, `Doc02Icon`, etc.).
- **Framer Motion**: Micro-animaciones fluidas para transiciones de estado, apertura de paneles laterales y modales de permisos.
- **Zustand**: Gestión reactiva de estado global (configuración de tema, modelos activos, carpetas vinculadas, tour interactivo).
