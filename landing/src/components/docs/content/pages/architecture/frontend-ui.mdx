## Interfaz vigente

El renderer principal vive en `desktop/frontend-spartan`. React presenta conversaciones, modelos, configuraciones y tarjetas de herramientas. Electron carga su build mediante un preload con aislamiento de contexto.

## Flujo de datos

```text
Interfaz React → API autenticada → Backend Python
       ↑                              ↓
Estado y tarjetas ← eventos y resultados
```

## Estado y suscripciones

El estado de conversación y ejecución se concentra en stores y módulos de características. Las actualizaciones de streaming deben evitar renders innecesarios de componentes que no cambiaron.

## Comprobaciones

El tipado no sustituye las pruebas de comportamiento. La suite contiene pruebas funcionales y aserciones sobre código fuente; estas últimas necesitan adaptación cuando se divide un módulo.
