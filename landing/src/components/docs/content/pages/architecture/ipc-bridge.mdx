# Puente IPC y Protocolo de Comunicación

Para garantizar la máxima seguridad y rendimiento, Sparta Agent utiliza una arquitectura de **Puente IPC (Inter-Process Communication)** fuertemente tipada.

---

## 🔒 Canales IPC Principales

1. **`system.channel.ts`**:
   - Monitoreo de recursos del sistema (CPU, VRAM, RAM, estado de la red).
   - Detección de versiones y comprobación de actualizaciones de la aplicación.
2. **`mcp.channel.ts`**:
   - Invocación de herramientas MCP (`mcp:call-tool`).
   - Envío de streams y recepción de eventos de progreso.
3. **`dialog.channel.ts`**:
   - Selector nativo de archivos y carpetas del sistema operativo.
4. **`window.channel.ts`**:
   - Control de ventana nativa (minimizar, maximizar, cerrar, modo pantalla completa).

---

## 🛡️ Aislamiento de Contexto

El script de `preload` expone únicamente APIs seguras e inmutables a la capa de renderizado web a través de `contextBridge.exposeInMainWorld`, evitando cualquier inyección no autorizada o acceso directo a Node.js desde la ventana web.
