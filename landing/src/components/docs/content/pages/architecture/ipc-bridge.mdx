# Puente IPC Seguro

La comunicación entre el proceso de renderizado de Electron, el proceso principal y el sidecar de Rust se realiza a través de un canal de **comunicación inter-procesos (IPC)** tipado y validado criptográficamente.

---

## Principios del Puente IPC

1. **Esquemas Tipados (Type-Safe RPC)**: Cada método IPC expuesto cuenta con definiciones de tipos TypeScript y Rust sincronizadas, evitando fallos de serialización en tiempo de ejecución.
2. **ContextBridge de Electron**: El renderer no tiene acceso a Node.js nativo ni a APIs de sockets directas; interactúa exclusivamente a través de métodos seguros expuestos en `window.spartaAPI`.
3. **Validación de Payloads**: Cada solicitud se valida contra esquemas de datos antes de transmitirse al ejecutor de herramientas o al permission broker.
