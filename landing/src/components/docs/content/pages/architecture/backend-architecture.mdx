# Arquitectura del Backend

El backend de Sparta Agent está construido en **Python 3.11+** sobre **FastAPI** y **Uvicorn**, diseñado para máxima concurrencia y baja latencia.

---

## 🏛️ Componentes Principales

```
[ FastAPI REST / SSE Endpoints ]
       │
       ├──► [ Inference Orchestrator ] ──► [ llama.cpp / External Providers ]
       ├──► [ ResearchSupervisor ]     ──► [ Background Worker Loop ]
       ├──► [ RAG Engine ]             ──► [ Embeddings + FTS5 SQLite ]
       └──► [ Storage Layer ]          ──► [ SQLite WAL: studio.db ]
```

### 1. Inferencia Unificada (`core/inference/`)
Gestiona el ciclo de vida de los modelos locales y externos:
- Carga y descarga dinámica de pesos en VRAM / RAM.
- Gestión de slots paralelos de inferencia.
- Despacho y ejecución de herramientas (`tools.py`).

### 2. Supervisor de Investigación (`core/research_runs.py`)
Maneja tareas en segundo plano (`ResearchSupervisor`) mediante colas durables en base de datos, soportando pausa, reanudación y tolerancia a fallos.

### 3. Capa de Persistencia (`storage/`)
SQLite en modo WAL (`journal_mode=WAL`) para lecturas y escrituras concurrentes sin contención de bloqueos.
