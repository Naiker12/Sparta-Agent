# Arquitectura del Backend y Rust Sidecar

El backend de Sparta Agent implementa un motor híbrido que combina la velocidad y seguridad de memoria de **Rust** con la flexibilidad de orquestación agéntica de **LangGraph**.

## Ventajas del Sidecar en Rust

1. **Latencia Sub-milisegundo**: Las operaciones de escaneo del workspace, cálculo de hashes y búsqueda con `ripgrep` se ejecutan en código nativo compiled sin sobrecarga de recolección de basura.
2. **Seguridad de Memoria**: Aislamiento estricto de hilos de ejecución mediante el sistema de tipos y borrow checker de Rust.
3. **Consumo de Memoria Optimizado**: El sidecar en segundo plano mantiene un footprint de RAM inferior a 45 MB en reposo.
