# Sparta Agent

**Sparta Agent** es un asistente y agente de inteligencia artificial de escritorio diseñado con una premisa fundamental: **control total, privacidad absoluta y capacidades avanzadas de ejecución autónoma**.

Funciona de forma **100% offline y local** utilizando modelos en formato GGUF mediante `llama.cpp` o Apple Silicon MLX, y también permite conectar proveedores en la nube (OpenAI, Anthropic, Google Gemini, DeepSeek, Groq, Ollama) bajo una capa unificada de seguridad.
