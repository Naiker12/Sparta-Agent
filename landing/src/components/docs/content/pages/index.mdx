Sparta Agent reúne conversaciones, modelos y herramientas en una aplicación de escritorio. Puedes trabajar con un modelo local o conectar un proveedor remoto, incorporar documentos al contexto y ejecutar tareas con herramientas habilitadas.

## Empieza con una tarea pequeña

La mejor forma de conocer Sparta es completar un cambio que puedas revisar: conectar un modelo, elegir una carpeta y pedir una explicación antes de solicitar una edición.

## Cómo se organiza el trabajo

1. **Contexto:** eliges el modelo, la conversación y los archivos relevantes.
2. **Acciones:** el modelo propone herramientas; la política activa decide cuáles requieren aprobación.
3. **Resultados:** Sparta muestra estados y salidas de las herramientas.
4. **Verificación:** revisas los archivos y ejecutas las comprobaciones adecuadas.

<Callout title="Local y remoto" type="info">El escritorio y su motor se ejecutan en tu equipo. Al usar un proveedor cloud o un conector externo, parte del contenido puede enviarse a ese servicio. Elige el modelo y las herramientas según los datos de tu tarea.</Callout>

## Cuando algo no funciona

Consulta [Diagnóstico y reparación](/docs/guides/troubleshooting) si el motor no inicia o una petición falla. Para tareas lentas, empieza por la [guía de rendimiento](/docs/guides/performance).
