# Sparta Agent

**Sparta Agent** es un entorno de desarrollo integrado (IDE) y agente de inteligencia artificial de escritorio diseñado bajo tres principios fundamentales: **control total del usuario, privacidad absoluta local-first y ejecución autónoma verificable**.

A diferencia de los entornos basados en la nube tradicionales, Sparta Agent opera con un motor de ejecución híbrido: la indexación de código, la terminal, el almacenamiento de secretos y la máquina de estados agéntica residen **100% en tu máquina local**.

## Tabla Comparativa de Capacidades

| Característica | Sparta Agent | IDEs Cloud Tradicionales | Extensiones Genéricas |
| :--- | :--- | :--- | :--- |
| **Residencia del Código** | 100% en tu máquina (Local-First) | Servidores de terceros | Servidores de terceros |
| **Modelos Locales (Ollama / vLLM)** | Soportado sin conexión | No disponible | Limitado |
| **Control de Permisos** | Diálogo modal obligatorio por acción | Automático sin aviso | No configurable |
| **Soporte MCP** | Nativo (Cliente IPC completo) | Parcial / Cerrado | Requiere plugins externos |
| **Almacenamiento de Secretos** | Vault local cifrado con AES-256 | Nube del proveedor | Texto plano / Variables de entorno |
| **RAG Multimodal** | Base de datos vectorial SQLite local | Indexación remota | No incluido |
