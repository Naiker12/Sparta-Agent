Sparta Agent reúne conversaciones, proveedores de IA por API y herramientas en una aplicación de escritorio. Configura una credencial, elige un modelo remoto, incorpora solo el contexto necesario y ejecuta tareas con herramientas habilitadas y aprobaciones explícitas.

## Empieza con una tarea pequeña

La mejor forma de conocer Sparta es completar un cambio que puedas revisar: conectar un modelo, elegir una carpeta y pedir una explicación antes de solicitar una edición.

## Cómo se organiza el trabajo

1. **Contexto:** eliges el modelo, la conversación y los archivos relevantes.
2. **Acciones:** el modelo propone herramientas; la política activa decide cuáles requieren aprobación.
3. **Resultados:** Sparta muestra estados y salidas de las herramientas.
4. **Verificación:** revisas los archivos y ejecutas las comprobaciones adecuadas.

<Callout title="Datos locales y solicitudes remotas" type="info">El escritorio, los proyectos y las herramientas se ejecutan en tu equipo. Al usar un proveedor de IA o un conector externo, el contenido incluido en la solicitud puede enviarse a ese servicio. Sparta Agent no descarga ni ejecuta modelos locales.</Callout>
