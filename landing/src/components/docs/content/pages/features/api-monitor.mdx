## Comprueba la conexión

Distingue un backend accesible de una credencial aceptada y de un modelo disponible. Una conexión puede responder y aun así rechazar una petición por cuota o capacidad.

## Consumo

Utiliza las métricas que reporte el proveedor. Si faltan tokens o precios, no interpretes un campo vacío como coste cero. Contrasta la facturación con el panel del servicio.

## Errores frecuentes

- **401:** credencial ausente, inválida o expirada.
- **429:** límite de peticiones o cuota del servicio.
- **Error de transporte:** URL, red o proceso no disponible.

## Diagnóstico seguro

Al reportar un problema, incluye el proveedor, el modelo y el mensaje de error, pero elimina tokens, claves y datos privados.
