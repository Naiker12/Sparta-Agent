## Disponibilidad

Las herramientas disponibles dependen del modo, la configuración, el proveedor y las conexiones activas. Un nombre visible en un catálogo no garantiza que la herramienta esté conectada o autorizada.

## Estados que debes revisar

| Estado | Qué significa |
|---|---|
| Preparando | Se están formando los argumentos |
| Esperando aprobación | Falta una decisión del usuario |
| Ejecutando | La llamada está en curso |
| Resultado | Hay una salida para inspeccionar |
| Fallo o cancelación | La acción no terminó normalmente |

## Acciones con archivos

Comprueba siempre la ruta y el alcance. Después de una escritura, solicita una lectura o una prueba para verificar el estado actual.

## Servicios externos

Para las herramientas MCP, consulta la [configuración de conexiones](/docs/mcp/configuration). Mantén activas solo las conexiones necesarias para tu tarea.
