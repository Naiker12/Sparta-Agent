# Herramientas en Vivo y Subagentes

Sparta Agent incluye un conjunto de herramientas internas de alta fidelidad que complementan el razonamiento del modelo y permiten interactuar con el entorno local y la web.

---

## Catálogo de Herramientas Principales

### 1. Navegación e Inspección Web (`read_url_content`)
Extrae el contenido textual limpio de páginas web públicas, documentación técnica y repositorios sin renderizar scripts pesados ni consumir recursos innecesarios.

### 2. Gestión de Tareas Asíncronas (`manage_task` / `schedule`)
Permite pausar, cancelar, enviar entradas de teclado a comandos activos y programar recordatorios o rutinas recurrentes de verificación de despliegue o pruebas.

### 3. Edición Precisa de Código (`replace_file_content` / `multi_replace_file_content`)
Aplica modificaciones quirúrgicas bloque por bloque en archivos existentes sin reescribir el archivo entero, reduciendo la latencia de generación de tokens y previniendo la pérdida accidental de código adyacente.

### 4. Búsqueda Rápida de Patrones (`grep_search` / ripgrep)
Integración nativa con `ripgrep` para localizar símbolos, funciones o referencias en cuestión de milisegundos en repositorios con miles de archivos.

---

## Subagentes de Propósito Específico

Cuando una tarea requiere una investigación autónoma o una ejecución paso a paso que excede una sola interacción, Sparta Agent puede instanciar subagentes especializados con contexto aislado y herramientas dedicadas.
