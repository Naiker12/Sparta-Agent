# Gestión de Archivos y Adjuntos

Sparta Agent permite arrastrar, soltar e indexar archivos directamente en el hilo de conversación, permitiendo al agente comprender el contexto exacto del problema sin necesidad de copiar y pegar fragmentos manualmente.

---

## Modos de Incorporación de Contexto

### 1. Adjuntos Directos en el Chat
Arrastra archivos (PDFs, imágenes de capturas de pantalla, archivos JSON o scripts) directamente a la caja de entrada para que el modelo los analice de forma inmediata.

### 2. Vinculación de Espacios de Trabajo (Workspaces)
Al seleccionar una carpeta como workspace activo:
- Sparta Agent indexa la estructura jerárquica de archivos.
- Reconoce automáticamente archivos de reglas (`.agents/AGENTS.md`).
- Rastrea el estado de `git` para identificar archivos modificados o pendientes de commit.

### 3. Presupuesto Inteligente de Tokens
El sistema administra de forma dinámica el contexto inyectado para evitar saturar la ventana de atención del modelo, priorizando fragmentos relevantes y resúmenes estructurados cuando los archivos son extensos.
