## Qué hace la recuperación

El sistema procesa fuentes y recupera fragmentos relevantes para una consulta. Reutiliza la infraestructura de documentos e índices del backend para complementar el contexto del modelo.

## Prepara las fuentes

Selecciona documentos relacionados con la tarea y espera a que termine su procesamiento. Comprueba el estado de indexación antes de evaluar la calidad de una respuesta.

## Formula una consulta verificable

```text
Busca en los documentos del proyecto cómo se configura la autenticación.
Indica los archivos y fragmentos que sustentan la respuesta.
```

## Revisa la evidencia

Recuperar fragmentos no equivale a leer todo el repositorio. Contrasta rutas y contenido, especialmente si los archivos cambiaron después de indexarse.

## Si falta información

Comprueba que la fuente pertenece al proyecto correcto, que el procesamiento terminó y que la consulta describe el concepto que buscas. Si necesitas el estado exacto de un archivo editado, utiliza una lectura directa.
