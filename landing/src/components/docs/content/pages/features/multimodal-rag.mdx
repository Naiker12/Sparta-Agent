## Alcance actual

La edición API-only de Sparta Agent no incluye RAG local, indexación vectorial, embeddings ni bases de conocimiento internas. Tampoco procesa documentos para crear un índice persistente. Esta decisión evita dependencias pesadas y deja claro qué contenido se entrega a un proveedor remoto.

## Cómo dar contexto al agente

Conecta un proyecto y usa las herramientas de archivos para leer rutas concretas, buscar texto en el workspace o adjuntar los documentos necesarios a una conversación. El modelo recibe solo el contenido que la solicitud y las herramientas aprobadas proporcionan; no se hace una búsqueda semántica automática sobre tu disco.

## Formula una consulta verificable

```text
Revisa `src/auth` y `README.md` para explicar cómo se configura la autenticación.
Indica los archivos leídos y no modifiques nada.
```

## Revisa el alcance y la evidencia

Leer un archivo concreto no equivale a comprender todo el repositorio. Pide al agente que cite rutas, revisa los cambios antes de aplicarlos y limita las herramientas al proyecto correcto. Si el contenido se envía a un modelo remoto, también aplica las políticas de privacidad del proveedor seleccionado.

## Si falta información

Indica rutas, nombres de símbolos o términos que el agente pueda buscar. Para el estado exacto de un archivo editado, usa lectura directa o la terminal con aprobación. No esperes que una base de conocimiento local complete automáticamente documentos que no hayas compartido en la tarea.
