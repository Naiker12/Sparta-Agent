# RAG Local Híbrido Multimodal

Sparta Agent cuenta con un motor de **Recuperación Aumentada por Generación (RAG)** híbrido que combina búsqueda vectorial de alta dimensionalidad con indexación léxica de texto completo (**BM25 / FTS5**), ejecutado de forma 100% local en una base de datos **SQLite-vec**.

## Formatos de Archivo Soportados

<Tabs items={['Documentos', 'Hojas de Cálculo', 'Bases de Código', 'Imágenes / OCR']}>
  <Tab value="Documentos">
    - **PDFs**: Extracción de texto y análisis estructural de tablas y columnas.
    - **Word (.docx)**: Procesamiento jerárquico de títulos, listas y párrafos.
    - **Markdown / Text (.md, .txt)**: Indexación con preservación de bloques de código.
  </Tab>
  <Tab value="Hojas de Cálculo">
    - **Excel (.xlsx, .xls)** y **CSV**: Conversión inteligente de esquemas tabulares a estructuras consultables por el agente.
  </Tab>
  <Tab value="Bases de Código">
    - **TypeScript, JavaScript, Python, Rust, Go, SQL, JSON**: Indexación basada en árboles sintácticos (AST) con reconocimiento de funciones, clases e imports.
  </Tab>
  <Tab value="Imágenes / OCR">
    - **PNG, JPG, WebP**: Reconocimiento óptico de caracteres y análisis visual mediante modelos con capacidades de visión por computadora.
  </Tab>
</Tabs>

## Ventajas de la Arquitectura Local

<Callout type="info">
  La base de datos vectorial y los embeddings se calculan en tu hardware local. Ninguna página de tus contratos, hojas financieras o código propietario se envía a servicios externos para su vectorización.
</Callout>
