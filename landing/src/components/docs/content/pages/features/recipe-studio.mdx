## Qué prepara una receta

Una receta describe un proceso de datos y sus configuraciones. Revisa entradas, modelos y destino antes de ejecutar un trabajo.

## Antes de ejecutar

Comprueba el formato del dataset y empieza con una muestra pequeña. Las capacidades de entrenamiento y generación de datos pueden necesitar dependencias y hardware adicionales al chat.

## Resultados

Revisa el estado del trabajo y el artefacto producido. Que una configuración se guarde correctamente no significa que el proceso haya terminado.

## Reproducibilidad

Conserva la configuración, la versión del modelo y una referencia a las entradas. No registres credenciales dentro de recetas compartidas.
