# Ejecución de Código y Terminal Multi-Shell

El motor de terminal de Sparta Agent permite ejecutar comandos de sistema operativo, suites de pruebas automatizadas y compilaciones directamente desde el flujo de trabajo del agente, manteniendo la salida y los logs asociados a la conversación.

---

## Características de la Terminal Integrada

### 1. Detección Automática de Shells
- **Windows**: PowerShell 7 / Windows PowerShell, Command Prompt, Git Bash y WSL.
- **macOS**: Zsh, Bash.
- **Linux**: Bash, Zsh, Fish.

### 2. Streaming de Salida en Tiempo Real
La salida estándar (`stdout`) y el flujo de errores (`stderr`) se transmiten de forma progresiva sin bloquear la interfaz gráfica de usuario.

### 3. Tareas en Segundo Plano (Background Tasks)
Para procesos de larga duración (servidores de desarrollo, suites de tests exhaustivas, compilaciones de Rust o descargas masivas), el agente puede enviar la tarea al fondo y recibir notificaciones asíncronas cuando finalice o requiera atención.

---

## Directivas de Ejecución Segura

- **Paginador Neutro**: Las llamadas configuran automáticamente `PAGER=cat` para evitar que comandos interactivos como `git log` o `less` queden esperando una pulsación de tecla.
- **Directorio de Trabajo Explícito (`cwd`)**: Toda ejecución debe validar que su directorio de trabajo pertenezca al workspace activo.
- **Cancelación Inmediata**: Cualquier comando en ejecución puede terminarse instantáneamente desde la interfaz con el botón de cancelación o mediante la herramienta de gestión de procesos.
