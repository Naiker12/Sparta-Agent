## Flujo de una llamada

La terminal presenta el comando solicitado por el modelo. Mientras se prepara, espera aprobación o se ejecuta, la tarjeta conserva el detalle del comando y el estado correspondiente.

## Comprueba el directorio

Antes de ejecutar una instalación o una prueba, confirma la carpeta de trabajo. Los comandos y las rutas dependen del sistema operativo; un ejemplo de Bash puede necesitar adaptación a PowerShell.

```text
Desde la carpeta del proyecto, ejecuta la prueba relevante para este cambio.
Indica el comando completo y conserva el error si la prueba falla.
```

## Lee la salida

Una ejecución puede finalizar, fallar, cancelarse o quedar pendiente. No interpretes un mensaje de preparación como prueba de éxito. Revisa el código de salida y los errores disponibles.

## Después de editar

Vuelve a leer el archivo o solicita un diff. La deduplicación permite esa nueva observación después de una herramienta que puede modificar el workspace, sin permitir repeticiones idénticas ilimitadas cuando el estado no cambia.

## Límites de interacción

El terminal IPC heredado utiliza pipes y no ofrece todas las capacidades de un pseudoterminal interactivo. No presupongas soporte de redimensionado o programas que exigen TTY.
